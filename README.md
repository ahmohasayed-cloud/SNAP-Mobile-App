# SNAP Test App

An installable test version of SNAP with a **fictional demo company**. It runs entirely on your phone: no server, no account.

- Open the page link on your phone.
- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** menu (⋮) → Install app (or Add to Home screen).
- Sign in with an Employee ID and password from the sign-in list you were given.
- Everything you change stays on that phone only. To go back to the original demo data, open the link with `?reset=1` at the end.
